# STM32F407 核心板引脚图

65 × 50 mm STM32F407VGT6 核心板的交互引脚图，对应 120 针板对板接口 V0.8。

在线查看：https://ningzixi.github.io/f407-core/

- 按外设（I2C、串口、SPI、PWM、ADC……）查看可用引脚
- 点击任意引脚查看 GPIO 编号与全部复用功能（AF 编号）
- 板图按真实 PCB 几何绘制，排母引脚与焊盘逐列对齐

复用功能数据来自 ST 官方 STM32CubeMX 引脚数据库（STM32F407VGTx）。

可以在网址后加 `#J1-29` 这样的编号，直接打开对应引脚。
